# Repositorios GitHub — Grupo Cordillera EP3
# DSY1106 Desarrollo Fullstack III

## Repositorio Principal (monorepo)
URL: https://github.com/frani3/Grupo-Cordillera-ET
Rama: rama-e3
Descripción: Repositorio principal con todos los componentes del
sistema: frontend SPA, BFF, 5 microservicios de negocio,
3 orquestadores, API Gateway Nginx, simuladores de datos,
documentación completa y pruebas unitarias.
